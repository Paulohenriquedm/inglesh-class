Estrutura de repeticao em java script

Vamos construir passo a passo e entender como funcionam os lacos for, while, do while

PASSO 1 - ESTRUTURA FOR

No HTML criamos um botão para executar o laço for e uma area para exibir o resultado

PASSO 2 - ESTRUTURA WHILE

Agora acionamos o botão para o laço While que executa enquanto a condição for verdadeira

PASSO 3 - ESTRUTURA DO WHILE

O Do While garante que o codigo seja executado pelo menos uma vez

PASSO 4 - ESTRUTURA FOR...OF

O FOR...OF percorre os valores de um array(ou uma string etc).

PASSO 5 - ESTRUTURA FOR...IN

O FOR...IN percorre as chaves ou indices de um objeto ou uma array

PASSO 6 - ESTRUTURA FOR...EACH()

O FOR...EACH() é uma forma mais recente de percorrer arrays, usando a função callback

PASSO 7 - METODO forListaSimples()

O METODO forListaSimples() percorre uma lista chave:valor
